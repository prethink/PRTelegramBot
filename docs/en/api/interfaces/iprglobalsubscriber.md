# IPRGlobalSubscriber

Interface of a global subscriber. Used by the EventBus system.

Inherits `IDisposable`.

## Methods

| Method | Description |
| --- | --- |
| `void Subscribe()` | Subscribes the instance to the EventBus events. |
| `void Unsubscribe()` | Unsubscribes the instance from the EventBus events. |
