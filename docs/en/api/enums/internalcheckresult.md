# InternalCheckResult

Internal check performed on commands before they run.

## Values

| Value | Description |
| --- | --- |
| `Passed` | The check passed. |
| `PrivilegeCheck` | Privilege check. |
| `WrongMessageType` | Invalid message type. |
| `WrongChatType` | Invalid chat type. |
| `NotInWhiteList` | The user is not on the white list. |
| `Custom` | A custom response. |
