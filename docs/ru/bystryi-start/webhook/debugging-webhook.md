# Debugging WebHook

Для того чтобы подебажить webook функционал, можно использовать софт **Ngrok**.

**Ngrok**— это сервис, который позволяет открыть доступ к внутренним ресурсам машины, на которой он запущен, из внешней сети, путем создания публичного адреса, все запросы на который будут переброшены на локальный адрес и заданный порт.

Скачать его можно по ссылке - [https://ngrok.com/download](https://ngrok.com/download)

Запускаем ngrok

<figure><img src="../../.gitbook/assets/изображение (24).png" alt=""><figcaption></figcaption></figure>

В консоле пишем команду ngrok http 8443. 8443 это порт вашего приложения, укажите порт с которым будете работать.

<figure><img src="../../.gitbook/assets/изображение (25).png" alt=""><figcaption></figcaption></figure>

Если все прошло удачно, должно появится окно как на скриншоте. Копируем выделенные адрес, указываем его в WebHook и дебажим.

<figure><img src="../../.gitbook/assets/изображение (26).png" alt=""><figcaption></figcaption></figure>
